# Benchmark Results: Accuracy and Selected Feature Count

This page reproduces the **complete 63-dataset** per-dataset comparison reported in Supplementary Tables **A5** (classification accuracy) and **A6** (selected feature count) for the Phoenix-OI manuscript. The identical table is also included in the [main README](../README.md#complete-63-dataset-benchmark-results) for convenient browsing.

**Table conventions:** Accuracy = mean ± standard deviation (%); `#Feat` = mean selected-feature count. Results compare Phoenix-OI, PSO, SFE, and SFE-PSO. These are manuscript-reported benchmark outcomes (30 independent runs per dataset), not output from a single example execution.

**Data and archived experiment results:** [Dataset63 Zenodo record](https://doi.org/10.5281/zenodo.22503472) (DOI: `10.5281/zenodo.22503472`). This repository does **not** include `data/*.csv` or `dataset63/` downloads; use the actual files and naming listed on Zenodo.
